# Android and iOS release handoff

The current source is not a production release. Provider/device acceptance and signing remain separate from compilation. Preserve the existing repository changes when reviewing this handoff.

## Android

Use JDK 21 and Android SDK platform 35. Run `npm run android:sync` before Gradle. When native Firebase configuration is absent, the sync step omits native Firebase plugins from the development bundle to preserve email startup; native providers/push are unavailable. Supply the real configuration and sync again before release. Build debug with `android/gradlew.bat :app:assembleDebug`; unsigned release packages with `:app:assembleRelease :app:bundleRelease`. Unsigned packages cannot be installed/published as a signed release.

For the operator's existing signing identity, set `ALLGO_KEYSTORE_PATH`, `ALLGO_KEYSTORE_PASSWORD`, `ALLGO_KEY_ALIAS`, `ALLGO_KEY_PASSWORD`, `ALLGO_VERSION_CODE` and `ALLGO_VERSION_NAME` in the secure local/CI environment. Run `:app:bundleRelease -PallgoRequireSigning` to require signing. Do not commit keystores or passwords. No signing identity is generated by this work.

Expected output paths: `android/app/build/outputs/apk/debug/app-debug.apk`, `android/app/build/outputs/apk/release/app-release-unsigned.apk`, and `android/app/build/outputs/bundle/release/app-release.aab`. The last path is unsigned unless signing configuration was supplied.

Native Firebase registrations, release signing fingerprints, provider activation and Play Integrity must match `in.allgo.app`. No device was attached at the initial ADB check. Connect the intended phone and review registration, all service screens, keyboard/safe areas, back navigation, real provider payments, permissions, push/deep links and offline/restart recovery.

## iOS

Windows cannot produce a signed iOS release. On macOS install current compatible Xcode/CocoaPods, run `npm run build`, `npx cap sync ios`, install pods and open `ios/App/App.xcworkspace`. Add actual Firebase plist and reversed Google client URL scheme; set the operator's team, bundle registration, provisioning and signing identity. Enable Apple Sign In, Push Notifications and Background Modes/Remote notifications, and configure APNs in Firebase. Register App Attest/DeviceCheck.

Archive and export through the operator's approved App Store Connect identity. Check native Google/Apple/phone flows, APNs token changes, permissions, booking links and checkout on a physical iPhone. No iOS archive, signature or upload has been produced here.

## Store content and review

- Review the new purple/white AllGo monogram icons in `release-assets` and replace remaining template launch assets with operator-approved branding before publication. Obtain actual Android/iPhone screenshots from the accepted build; do not submit reference mockups as app screenshots.
- Use the published operator privacy URL, terms, support contact, cancellation/refund and wallet conditions. Declare the actual authentication, address/location, chat, payment and partner identity data used by the app.
- Provide reviewer credentials and service coverage for a functioning staging/review account. Payment behavior must match the actual provider environment and review policy.
- Confirm account deletion requests/processing, permission purpose strings, accessibility, approved vehicle/service coverage, refund reconciliation, custom claims, App Check and monitoring.
- Prepare Play listing, feature graphic and Apple listing/localizations using approved service claims. Do not claim unsupported background tracking, guaranteed arrival times or instant bank withdrawals.
