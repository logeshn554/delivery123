# AllGo design system

The customer UI uses `src/design-system/tokens.css`. Purple is the brand action color. Food uses warm orange, grocery uses green, and other service colors are reserved for their corresponding workflows. Text uses dark ink on white or the pale canvas. Success, warning and error colors describe state only.

Use a 4px spacing base (`--allgo-space-*`), 16–20px card corners, a subtle card shadow and a 44px minimum touch target. Keep primary actions legible at narrow mobile widths. Real catalog images are displayed when provided; icon placeholders represent missing images. Do not introduce promotional claims, ratings, prices or delivery promises without valid application data.

Home prioritizes two shopping flows, then compact logistics links. The Services tab remains the complete directory. Activity uses the actual booking lifecycle. The address selector and cart remain persistent in the customer shell.
